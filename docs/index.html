THE OPERATOR SET

Four operators. One clear expression.

&AND
|OR
!NOT
~NEAR

Use parentheses when mixing AND and OR. The compiler preserves your operator order; it does not invent precedence. Escape literal operators with a backslash.

FROM YOUR RUST APPLICATION

Parse once. Use the result.

use es_keyword_query::Query;

let query = Query::parse("(tea|coffee)&shop!ad")?;
let text = query.to_query_string();
let terms = query.terms();
