# Locally served headline font

`barlow-condensed-latin-800-normal.woff2` is Barlow Condensed ExtraBold from
`@fontsource/barlow-condensed` 5.2.7. It is served from this directory; the page
makes no request to a font CDN.

- Official setup and family information: https://fontsource.org/fonts/barlow-condensed/use
- Published package: https://www.npmjs.com/package/@fontsource/barlow-condensed/v/5.2.7
